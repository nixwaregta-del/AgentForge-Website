Setup

How it works

AgentForge bridges your browser AI chat with Roblox Studio through a local Python bridge and browser extension.

1

Install Extension

Load the AgentForge extension in Edge or Chrome. It injects a control panel into supported AI chat sites.

2

Enable MCP in Studio

Open Roblox Studio, go to Assistant AI, and enable "Studio as MCP Server" in the MCP settings.

3

Run the Bridge

Double-click start.bat (Windows) or MacOS_Start.command (macOS). The bridge connects the extension to Studio.

4

Chat to Build

Open a supported AI chat, start a session, and tell the agent what to build. It drives Studio directly.
